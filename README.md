# Organization

该仓库是 InteropAtlas GitHub Organization 的组织级公共工作空间，也是**不属于任何单一项目、但属于整个组织**的身份、方向、治理与跨项目事务的主要载体。

This repository is the primary home for organization-level identity, direction, governance, and cross-project matters that do not belong to any individual project.

## 最短介绍

### 我们做什么
**探索组织的边界。**

发现组织还可以是什么，并通过真实构建扩展组织的可能空间。

### 我们怎么做
**通过构建、运行、观察和持续修改真实组织来研究组织。**

组织自身也是实验对象。

### 这些成果最后去哪
**可公开的研究、方法、实验结果、工具和可复用经验，在条件允许时尽可能重新进入公共知识领域。**

更完整定义见 `01_Identity/FOUNDATIONS.md`。

## 主要入口

- `01_Identity/` — 我们是谁、在探索什么、如何工作；
- `02_Projects/` — 我们正在创造什么，以及组织内项目之间的关系；
- `03_Evolution/` — 我们正在讨论、探索和改变什么，以及为什么改变。

## 边界

这个仓库不是组织的私有后台，而是组织的 **public organizational layer**。适合公开的身份、方向、跨项目原则、治理与演化记录。

财务、账号权限、安全信息、个人信息、未公开合作等不应因为“属于组织”就进入这个公共仓库。

## 当前状态

组织名称与更完整的组织结构尚未最终确定。本仓库先由真实需求驱动，以最小结构运行；未来只有在出现稳定需求时才继续扩展。
