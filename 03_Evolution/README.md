# 03 Evolution

回答：**我们正在讨论、探索和改变什么，以及为什么改变。**

这里保存具有长期价值的组织级演化记录，例如跨项目研究、重要方向变化与已经值得留下的决策过程。

实时、尚未收敛的组织级讨论优先使用 Organization Discussions。只有需要长期恢复上下文、解释“为什么变成现在这样”的内容，才沉淀到本目录。

## 当前值得保留的探索线索

- **组织作为类生命复杂系统**：用生命的连续性、互操作、适应与演化来帮助理解组织，但不把组织简单等同于生命。
- **组织边界**：研究多个相对自主主体如何通过持续耦合形成整体，并探索这种“组织性”能够发展出哪些形态、能力与边界。
- **边界对象**：除人类组织、Agent 组织与人机混合组织外，也允许动物群体、植物网络、菌落、生态网络等进入研究视野，作为边界案例或参照对象。
- **组织与项目的相互塑造**：项目不只是组织的产出，也可能成为组织基础能力的一部分；项目运行中暴露的问题可以推动组织本身演化。
- **IA 的基础作用**：互操作不仅是 IA 自己的研究对象，也可能是上层组织形成多主体协作、知识传递与多种呈现方式的重要基础条件。

这些内容仍属于开放探索，不应因为被记录在这里就被视为已经冻结的最终理论。

这个目录不应成为所有讨论的归档箱。
