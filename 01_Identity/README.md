# 01 Identity

回答：**我们是谁、为什么存在、希望促成什么，以及叫什么。**

这里保存相对稳定、属于整个组织而非某个单一项目的身份与方向材料。

## Canonical foundations

组织级哲学、愿景、使命、变化模型与实现原则统一定义在：

- [`FOUNDATIONS.md`](FOUNDATIONS.md) — Philosophy / Vision / Mission / Change Model / Principles，以及它们与 InteropAtlas 的关系。

其中最核心的层级是：

**Philosophy / 世界观** → 我们相信什么  
**Vision / 愿景** → 如果长期成功，希望世界呈现什么状态  
**Mission / 使命** → 我们为何存在、持续推动什么变化  
**Change Model / 变化模型** → 我们认为变化如何发生  
**Principles / 原则** → 实现过程中坚持什么  
**Projects / 项目** → 在具体问题空间中的实践
