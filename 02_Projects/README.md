# 02 Projects

回答：**我们正在创造什么，以及这些项目为什么对组织重要。**

这里描述组织内项目的整体关系、边界与跨项目事项，而不是复制各项目自己的文档。

## 当前项目

### InteropAtlas

**InteropAtlas 是当前组织中的首个主要项目。** 其项目级知识、设计、运行与治理仍以 `InteropAtlas/InteropAtlas` 仓库为 Primary Home。

IA 对上层组织的意义，不只是“有一个互操作项目”。它提供了一类非常基础的能力：帮助不同主体、系统和知识表达之间实现连接、理解与协同。

当前可以把 IA 对组织的作用理解为三点：

1. **连接主体**：研究不同主体如何互通、对齐与协同，为人、Agent、软件和其他系统共同组成组织提供基础。
2. **连接知识与表达**：研究同一知识如何被不同主体读取、理解和呈现，包括 Human / Agent、多视图、多表达与机器可读形式之间的转换。
3. **反过来推动组织实验**：真实组织运行会暴露新的互操作问题；IA 的研究成果又会让组织获得新的组合方式和协作能力。

因此，IA 既是独立项目，也可能逐渐成为组织的一层基础能力。

## 尚未立项、但已经出现的候选方向

以下内容只是当前研究中出现的**候选基础能力 / 候选项目方向**，尚未正式立项，也不代表最终项目划分。

### 1. 组织连续性

核心问题：**一个组织如何在成员、Agent、项目和时间不断变化时，仍然保持“还是同一个组织”。**

当前已经出现的相关机制包括 State、Checkpoint、Constitution、决策记录、项目状态与可恢复上下文等。可以把它类比为生命系统维持自身连续性的能力。

### 2. 组织适应与评估

核心问题：**组织如何知道自己的改变有没有带来更好的结果，并据此继续调整。**

可能涉及组织实验、比较不同协作方式、观察失败模式、评估不同拓扑 / 规则 / 人机协作方式，并把有效经验沉淀为可复用知识。

### 3. 组织表示与设计

核心问题：**一个组织应该怎样被描述，才能被理解、比较、修改和复现。**

当前已有的拓扑、角色、团队模板、状态、规则等概念都与此有关。这个方向未来是否形成独立项目仍保持开放。

## 当前不做的事

现在不急于把所有基础能力拆成独立仓库或独立项目。只有当某个方向形成持续工作、明确边界和独立产出后，才正式立项。
